# STAR

STAR is the prior-knowledge construction module used by InferCG. Its role is to generate the function knowledge base for a target Python project, including function annotations, import relations, inheritance information, and dependency-related metadata.

## What STAR Produces

Running STAR generates artifacts used later by InferCG:

- `depData/`: collected dependency information
- `pre_knowledge/`: generated function and entity knowledge base
- `result/`: generated call graph outputs from STAR itself

Important files in `pre_knowledge/` include:

- `*_pre_annotations.json`
- `*_import_info.json`
- `*_pre_inherited.json`

## Usage

Arguments:

- `pro_name`: project name
- `pro_path`: source path of the target project
- `depconfig_path`: dependency configuration path, for example `setup.py`, `requirements.txt`, or the project root

## Requirement

- Python 3.9

## Relation To InferCG

InferCG consumes the prior knowledge generated by STAR from `pre_knowledge/`. In other words, STAR is the stage that prepares the function knowledge base before call-edge inference starts.
