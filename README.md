# InferCG

InferCG is a call graph construction project for Python codebases. This repository contains the core inference pipeline, the intermediate artifacts used by the pipeline, the training data generation scripts, and the fine-tuning code for learned call-edge classification.

## Overview

InferCG combines three kinds of signals:

- Static call graph candidates produced by tools such as `PyCG` and `Depends`
- Prior knowledge generated by `STAR`
- LLM or fine-tuned code models for call-edge judgment

In this repository, `STAR` is used to generate the function knowledge base for a target project. More concretely, it extracts function/class/import information and writes the prior knowledge files consumed by InferCG, such as:

- `STAR/pre_knowledge/*_pre_annotations.json`
- `STAR/pre_knowledge/*_import_info.json`
- `STAR/pre_knowledge/*_pre_inherited.json`

These artifacts are then used to construct candidate caller-callee pairs and to support downstream call graph inference.

## Repository Structure

- `src/`: main InferCG pipeline and LLM adapters
- `STAR/`: prior-knowledge construction pipeline used to build the function/entity knowledge base
- `PyCG_data/`: static call graphs generated by PyCG
- `Depends_data/`: static call graphs generated by Depends
- `Ae_data/`: inferred call graph results
- `file2class_data/`: file-to-class relations generated during post-processing
- `stdlib_and_thirdlib_data/`: standard-library and third-party-library call results
- `ground-truth-cgs/`: ground-truth call graphs
- `ground-truth-cgs-after/`: cleaned or post-processed ground truth data
- `script/`: dataset generation and processing scripts
- `Finetuning/`: fine-tuning scripts for CodeBERT and CodeT5

## Pipeline

1. Use `STAR` to build the function knowledge base and prior knowledge for each target project.
2. Use a static analyzer  to provide an initial call graph.
3. Run InferCG in `src/main.py` to expand and refine candidate edges with prior knowledge plus model-based reasoning.
4. Write the final outputs into `Ae_data/`, `file2class_data/`, and `stdlib_and_thirdlib_data/`.

## Data and Outputs

Main intermediate or final data directories:

- `STAR/pre_knowledge/`: function annotations, import relations, inheritance information
- `PyCG_data/` and `Depends_data/`: static-analysis results
- `Ae_data/`: final inferred call graphs
- `file2class_data/`: file-class mappings
- `stdlib_and_thirdlib_data/`: inferred calls to stdlib and third-party APIs

## How To Run

### 1. Generate prior knowledge with STAR

See `STAR/Readme.md`. STAR is responsible for generating the function knowledge base used by InferCG.

Typical output folders:

- `STAR/depData/`
- `STAR/pre_knowledge/`
- `STAR/result/`

### 2. Run InferCG

The main entry is:

```bash
cd src
python main.py
```

`src/main.py` reads:

- static call graph inputs from `../PyCG_data/` or `../Depends_data/`
- prior knowledge from `../STAR/pre_knowledge/`
- source files from `../STAR/repo/`

and writes:

- `../Ae_data/`
- `../file2class_data/`
- `../stdlib_and_thirdlib_data/`

### 3. Generate training data or fine-tune models

- `script/generate_traindata.py`
- `script/generate_traindata_banlance.py`
- `script/generate_testdata.py`
- `Finetuning/finetuning_codebert.py`
- `Finetuning/codet5.py`

## Environment
