# InferCG

InferCG constructs Python call graphs by combining static-analysis candidates, prior knowledge generated by STAR, and optional LLM-based call-edge filtering.

## Features

- Generates candidate call graphs for a Python project.
- Builds function, import, and inheritance knowledge with STAR.
- Optionally filters candidate edges with an OpenAI-compatible LLM endpoint.
- Records output graphs, inference checkpoints, and run metrics as JSON files.

## Repository Layout

- `src/`: InferCG CLI and automation scripts.
- `STAR/`: prior-knowledge construction pipeline and benchmark repositories.
- `PyCG_data/` and `Depends_data/`: static-analysis inputs.
- `Ae_data/`: generated call graph results and metrics.
- `file2class_data/`: file-to-class relations produced during internal-call processing.
- `stdlib_and_thirdlib_data/`: standard-library and third-party call results.
- `ground-truth-cgs/` and `ground-truth-cgs-after/`: benchmark ground-truth graphs.
- `script/` and `Finetuning/`: dataset generation and model fine-tuning utilities.

## Prerequisites

- Python 3.9 or later.
- A supported Python environment with the runtime packages used by the pipeline:

```bash
python -m pip install openai transformers torch psutil tqdm
```

For LLM inference, set an API key for an OpenAI-compatible provider. Do not commit the key to the repository.

```bash
# PowerShell
$env:OPENAI_API_KEY = "your-api-key"
$env:OPENAI_BASE_URL = "https://api.example.com/v1"
```

## Quick Start

Run the main CLI from the repository root. The project name must correspond to STAR knowledge files such as `STAR/pre_knowledge/<project>_pre_annotations.json` and source code under `STAR/repo/<project>/`.

```bash
# Generate candidates only; no online model calls.
python src/main.py --project asciinema --mode candidates --all-or-ea 1

# Filter candidates with an OpenAI-compatible model.
python src/main.py --project asciinema --mode infer --all-or-ea 1 --model gpt-5.4
```

Set `OPENAI_BASE_URL` for an OpenAI-compatible provider, or override it for a single command with `--base-url`:

```bash
python src/main.py --project asciinema --mode infer --base-url https://api.example.com/v1
```

## Prepare A New Project

`generate_call_graphs.py` automatically invokes STAR to build the prior-knowledge artifacts and download the target project's required function libraries. Do not run STAR manually first.

```bash
python src/generate_call_graphs.py path/to/my_project --names my_project --all-or-ea 0
```

The script writes the candidate graph and metrics to `Ae_data/` by default. It reuses existing STAR artifacts when available; add `--rebuild-library` to regenerate the artifacts and download dependencies again.

## Batch Benchmark

Run the included static-project benchmark:

```bash
# Candidate generation only.
python src/run_static_benchmark_projects.py

# LLM filtering with two concurrent requests.
python src/run_static_benchmark_projects.py --mode infer --workers 2

# Rebuild output graphs from saved LLM checkpoints without API requests.
python src/run_static_benchmark_projects.py --mode infer --checkpoint-only
```

The batch script uses `all-or-ea=1` for `asciinema`, `autojump`, `fabric`, `face_classification`, and `Sublist3r`. It uses `all-or-ea=0` for `bpytop`, `furl`, `rich_cli`, `sqlparse`, `sshtunnel`, and `textrank4zh`.

## `all-or-ea` Modes

`--all-or-ea` controls which call edges are considered:

- `0`: internal project calls only; third-party dependencies are excluded.
- `1`: include third-party and external dependency calls.

Use the same mode for generating and evaluating a graph.

## Outputs

For a project named `my_project`, InferCG writes:

- `Ae_data/my_project.json`: generated call graph.
- `Ae_data/my_project.metrics.json`: run duration, memory, candidate-count, and inference metrics.
- `Ae_data/my_project.infer.checkpoint.json`: resumable LLM inference checkpoint when `--mode infer` is used.
- `file2class_data/my_project.json`: file-to-class mappings when `--all-or-ea 0` is used.

Use `--output` and `--metrics-output` to place the call graph and metrics elsewhere.

## Evaluation

Evaluate the configured static-project outputs against `ground-truth-cgs-after/`:

```bash
cd src
python evaluate_static_projects.py
```
